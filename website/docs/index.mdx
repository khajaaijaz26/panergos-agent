## Install

Panergos 0.1 is source-only; it does not publish prebuilt desktop installers. Install the CLI from this repository, then run `panergos desktop` to build and launch the desktop application from the managed checkout.

#### Linux / macOS / WSL2 / Android (Termux)

```bash
curl -fsSL https://raw.githubusercontent.com/khajaaijaz26/panergos-agent/main/scripts/install.sh | bash
```

#### Windows (native)

Run in powershell:

```powershell
iex (irm https://raw.githubusercontent.com/khajaaijaz26/panergos-agent/main/scripts/install.ps1)
```

See the full **[Installation Guide](/getting-started/installation)** for what the installer does, the per-user vs root layout, and Windows-specific notes. For the complete platform support matrix, see **[Platform Support](/getting-started/platform-support)**.

:::tip Fastest path to a working agent
After installing, run `panergos model --quick` for the shortest path to a ready local or cloud model, then run `panergos`.
:::

## What is Panergos Agent?

Panergos provides CLI, desktop, gateways, providers, tools, skills, memory, plugins, MCP, scheduling, delegation, and Durable Missions for restart-safe coordination. See [PANERGOS.md on GitHub](https://github.com/khajaaijaz26/panergos-agent/blob/main/PANERGOS.md) for implemented boundaries and roadmap status.

| Capability | Delivery | Status |
|---|---|---|
| CLI, TUI, desktop, web dashboard, and IDE/ACP surfaces | Source distribution | Available |
| Providers, tools, memory, skills, plugins, MCP, cron, gateways, and delegation | Source distribution | Available; covered by integration tests |
| Durable mission state, Kanban-backed task graphs, peer messages, and audit events | Built in | Experimental in 0.1 |
| Capability Forge, Policy Ledger, and comparative Evidence Gates | Not shipped | Planned; not a release claim |

Panergos does not claim universal superiority. Any future comparison will publish its inputs, pinned commits and model configurations, graders, repeated trials, failures, cost, and latency so others can reproduce it.

## Key Features

- **A closed learning loop** — Agent-curated memory with periodic nudges, autonomous skill creation, skill self-improvement during use, FTS5 cross-session recall with LLM summarization, and [Honcho](https://github.com/plastic-labs/honcho) dialectic user modeling
- **Runs anywhere, not just your laptop** — 7 terminal backends: local, Docker, SSH, Daytona, Singularity, Modal, Vercel Sandbox. Daytona and Modal offer serverless persistence — your environment hibernates when idle, costing nearly nothing
- **Lives where you do** — CLI, Telegram, Discord, Slack, WhatsApp, Signal, Matrix, Mattermost, Email, SMS, DingTalk, Feishu, WeCom, Weixin, QQ Bot, Yuanbao, BlueBubbles, Home Assistant, Microsoft Teams, Google Chat, and more — 20+ platforms from one gateway
- **Provider flexibility** — Connect local runtimes, hosted models, OpenAI-compatible endpoints, or the provider accounts you already use
- **Scheduled automations** — Built-in cron with delivery to any platform
- **[Bot Mode](/user-guide/bot-mode)** — Build a durable team of specialist Bots that work together in group chats and through `@mentions`
- **Delegates & parallelizes** — Spawn isolated subagents for parallel workstreams. Programmatic Tool Calling via `execute_code` collapses multi-step pipelines into single inference calls
- **Open standard skills** — Compatible with [agentskills.io](https://agentskills.io). Skills are portable, shareable, and community-contributed via the Skills Hub
- **Full web control** — Search, extract, browse, vision, image generation, and TTS through configurable providers
- **MCP support** — Connect to any MCP server for extended tool capabilities
- **Research tooling** — Batch processing, trajectory export, and RL training workflows
