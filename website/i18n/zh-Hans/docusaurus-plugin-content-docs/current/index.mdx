## 安装

**Linux / macOS / WSL2**

```bash
curl -fsSL https://raw.githubusercontent.com/khajaaijaz26/panergos-agent/main/scripts/install.sh | bash
```

**Windows（原生，PowerShell）** — _早期测试版，[详情 →](/user-guide/windows-native)_

```powershell
iex (irm https://raw.githubusercontent.com/khajaaijaz26/panergos-agent/main/scripts/install.ps1)
```

**Android（Termux）** — 与 Linux 相同的 curl 一行命令；安装程序会自动检测 Termux。

请参阅完整的 **[安装指南](/getting-started/installation)**，了解安装程序的具体操作、按用户与 root 的目录布局以及 Windows 相关说明。

## Panergos Agent 是什么？

Panergos 提供 CLI、桌面端、网关、提供商、工具、技能、记忆、插件、MCP、调度、委派和用于重启安全协调的 Durable Missions。当前 0.1 版本仅提供源码安装，不发布预构建桌面安装程序。

| 能力 | 交付方式 | 状态 |
|---|---|---|
| CLI、TUI、桌面端、Web 控制台及 IDE/ACP 界面 | 源码发行版 | 可用 |
| 提供商、工具、记忆、技能、插件、MCP、定时任务、网关及委派 | 源码发行版 | 可用；兼容性由集成测试覆盖 |
| 持久任务状态、基于 Kanban 的任务图、点对点消息及审计事件 | 内置 | 0.1 中为实验性功能 |
| Capability Forge、Policy Ledger 及对比 Evidence Gates | 尚未发布 | 规划中，并非当前发行声明 |

Panergos 不声称全面优于其他智能体。未来的任何对比都会发布输入、固定提交与模型配置、评分器、重复试验、失败记录、成本和延迟，以便复现。

## 核心功能

- **闭环学习循环** — 智能体管理的记忆，配合定期提示、自主技能创建、使用中的技能自我改进、基于 FTS5 的跨会话召回与 LLM 摘要，以及 [Honcho](https://github.com/plastic-labs/honcho) 辩证式用户建模
- **随处运行，不限于本地** — 6 种终端后端：本地、Docker、SSH、Daytona、Singularity、Modal。Daytona 和 Modal 提供 serverless 持久化——环境闲置时休眠，几乎零成本
- **在你所在的地方** — CLI、Telegram、Discord、Slack、WhatsApp、Signal、Matrix、Mattermost、Email、SMS、DingTalk、Feishu、WeCom、Weixin、QQ Bot、Yuanbao、BlueBubbles、Home Assistant、Microsoft Teams、Google Chat 等——通过一个网关支持 20+ 平台
- **定时自动化** — 内置 cron，可向任意平台投递
- **委托与并行** — 派生隔离的子智能体以并行处理多个工作流。通过 `execute_code` 实现程序化工具调用，将多步骤流水线压缩为单次推理调用
- **开放标准技能** — 兼容 [agentskills.io](https://agentskills.io)。技能可移植、可共享，并通过 Skills Hub 接受社区贡献
- **完整的 Web 控制** — 搜索、提取、浏览、视觉、图像生成、TTS
- **MCP 支持** — 连接任意 MCP 服务器以扩展工具能力

## 面向 LLM 和编程智能体

本文档的机器可读入口：

- **[`llms.txt`](https://khajaaijaz26.github.io/panergos-agent/docs/llms.txt)** — 每个文档页面的精选索引，附简短描述，可安全加载到 LLM 上下文中。
- **[`llms-full.txt`](https://khajaaijaz26.github.io/panergos-agent/docs/llms-full.txt)** — 所有文档页面拼接为单一 markdown 文件，支持一次性摄取。

两个文件每次部署时都会重新生成，并复制到项目 Pages 根路径以兼容探测根路径的客户端。
