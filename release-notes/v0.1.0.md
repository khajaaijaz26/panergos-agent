# Panergos Agent v0.1.0

Panergos Agent is an independent, model-agnostic agent runtime. This first release
combines a distinct public identity and release channel with durable multi-session
coordination. See the repository `NOTICE` and `LICENSE` files for legal provenance
and licensing terms.

## Highlights

- **Durable Missions:** persistent mission metadata, Kanban-backed task graphs,
  scoped actors, idempotent operations, typed compare-and-swap state, addressed
  messages, a replayable event stream, and recoverable stop fences.
- **Project Memory:** local incremental source indexing, compact SQLite FTS5
  retrieval with file-and-line evidence, and per-project handoffs for resuming work.
- **Model quick-start:** one guided command for existing Ollama, LM Studio, llama.cpp,
  a managed local runtime, Anthropic, or another OpenAI-compatible endpoint; key
  values remain outside the configuration file.
- **Unified connectors:** dynamic inventory and guided setup over every built-in or
  enabled plugin platform, including WhatsApp QR/local bridge and Meta WhatsApp Cloud
  API, plus secret-free local health output and provider-account onboarding.
- **Truthful Telegram onboarding:** manual BotFather setup is the local-first default;
  operators can optionally configure their own compatible onboarding service through
  `TELEGRAM_ONBOARDING_URL`.
- **Organization workflows:** a bundled professional role pack for individual,
  manager, department, and executive work across finance, HR, sales, marketing,
  support, operations, procurement, legal/compliance, engineering/IT/security,
  product, and analytics, with explicit approval and evidence stages.
- **Digital campaign workflow:** an optional governed path from research and asset
  generation through exact approval, connected-account publishing, provider read-back,
  measurement, and an honest handoff when a channel has no write connector.
- **Model Foundry:** an optional data-to-serving lifecycle for training or adapting
  user-owned models, plus a deterministic standard-library CPU smoke trainer that
  validates artifacts without a GPU or model download.
- **Media and authorized security:** provider-routed image/video generation and
  production workflows, plus defensive and allowlist-bound web-assessment routes.
- **Browser workspace:** the local dashboard embeds the real TUI through POSIX PTY or
  Windows ConPTY and now carries the Panergos Knot with the Eclipse jade/plum theme.
- **Independent identity:** the Panergos Knot logo and an accessible jade/coral/deep-
  ink theme across the website, dashboard, desktop, and bootstrap installer.
- **Independent trust roots:** Panergos-owned update, catalog, documentation, and MCP
  client-metadata routes. The `panergos` command is canonical; retired aliases are removed.
- **Provider-neutral runtime:** the CLI, TUI, desktop, API, gateways,
  tools, skills, plugins, MCP, browser, cron, delegation, checkpoints, session recall,
  and model-provider support remain available.

## Install from source

```bash
git clone --branch v0.1.0 --single-branch https://github.com/khajaaijaz26/panergos-agent.git
cd panergos-agent
uvx --from uv==0.9.28 uv sync --locked --python 3.11
uv run --frozen panergos setup
```

This is a **source-only release**. It does not include signed desktop installers or a
prebuilt container image. Build the desktop or container locally from this tag if needed.

## Boundaries

- Panergos does not bypass operating-system permissions, provider quotas, budgets,
  context windows, laws, or approval gates.
- Durable Mission policy is enforced through the `panergos_mission` interface;
  direct Kanban callers are trusted and can bypass that layer.
- A configured provider/account, its permissions, and exact approval remain required
  for external publication; Panergos never treats a generated file as proof of upload.
- Local inference has no Panergos API fee, but local hardware and electricity still
  have costs; Panergos does not bundle or promise a free cloud GPU.
- Mission budgets, signed binaries, comparative performance claims, Capability Forge,
  Policy Ledger, and unified Evidence Gates remain roadmap items.
